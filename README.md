# City Super Shoppee

A simple inventory webpage for City Super Shoppee, organized into category-wise sections with expandable tables.

## Updating the Inventory

Daily item updates are made in **`inventory.json`**. The webpage reads the data from this file, so there is no need to manually edit the HTML for normal inventory changes.

## Features

- Category-wise inventory sections
- Expand/collapse chevrons
- Item names, codes, quantities, MRP, and brands
- Mobile-friendly layout
- Clean presentation for sharing the current inventory/progress

## Main Files

- `index.html` — main inventory webpage
- `inventory.json` — master inventory data
- `v1.html` — previous/reference version
- `assets/` — images and other page assets
